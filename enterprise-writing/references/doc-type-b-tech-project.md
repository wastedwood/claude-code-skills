# B 类：科技计划项目申报书

## 语体

**学术论证体**。读者是同行技术评审专家，不是政府官员。

## 深层语言规则

1. **计划语态是硬约束**："拟解决"不是"将解决"，"拟开展"不是"要开展"，"旨在"不是"目的是"。全文用计划语态（present-future, not past）。
2. **"问题→分析→路径"三段句**：每段开头先定义科学/工程问题（"XX是限制YY的瓶颈"），中间做技术分析（"探索...深入研究...明确..."），末尾落到解决路径（"建立...方法，实现...目标"）。
3. **术语密度高且不加解释**：假定读者是同行评审专家。如"多相永磁推进电机多物理耦合约束下多目标优化设计技术"直接使用，不加括注。
4. **禁用口语承转**：不用"接下来""然后""还有"。用"在此基础上""与此同时""进一步地""鉴于此"。
5. **少用被动语态**：不用"被设计""被实现"，用主动句。
6. **"一句到底、分号串联"——需求目标（研究内容）的规范写法**：
   - 结构：`针对XX需求（或问题），研究XX方法/技术，突破XX瓶颈/局限，解决XX等难题，实现XX目标；研究XX技术，形成XX方案；研究XX技术，通过XX方法/手段，实现XX目标；研制（或开发）XX产品，突破XX技术，实现XX。`
   - 科技部指南典型写法：`研究XX方法/技术；研究XX技术；研究XX技术；研制XX产品。`
   - 分句之间用分号，不用句号断开，全段一个句号到底
   - 开头可以加"针对XX问题"或"存在XX问题"
7. **动词具体化原则**：优先用具体的技术动作替代抽象概括：
   - ✅ 研究、研发、突破、攻克、建立、构建、研制、开发、形成、实现
   - ✅ 通过XX方法，实现XX参数≥XX
   - ❌ 避免通篇"提升XX水平""增强XX能力"——能用具体指标就用具体指标
8. **考核指标写法**：
   - 结构：`研制（或建立/开发）XX产品（或系统/平台），XX参数≥XX或XX参数≤XX；在XX场景开展示范/验证不少于X处；申请发明专利不少于X项，制定标准不少于X项。`
   - 所有指标必须可量化（≥/≤），不可有主观性描述
   - 参考格式：`XX效率≥XX%；XX精度≤XX；体积≤XX；检测限≤XX`

# C 类：工程研究中心/平台申请报告

## 语体

**战略叙事体**。论证核心不是"技术怎么做"（那是科技申报书），而是"平台够不够格成为省级/国家级创新平台、能不能持续运转好"。

## 语言特征

- "聚焦""紧扣""立足""面向"——定义战略格局
- "系统构建了""全面打通""深度整合"——证明综合能力
- 管理机制内容占25-30%，是必答题也是高度模板化的部分
- 三个研究方向表述必须是"打包式"的学科化名称（如"高功率密度拓扑结构设计与多物理场协同数字仿真技术"）
- 产学研协同是必答题——写清楚依托单位和共建单位如何分工互补
- 喜欢用数字概括（"三引领""三个方向""一是...二是...三是..."）

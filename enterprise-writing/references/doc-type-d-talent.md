# D 类：人才申报书

## 语体

**个人履历体**。论证对象是个人（不是企业、不是技术、不是平台）。核心论证："这个人够不够格称为领军人才"。

## 语言特征

### 人称切换规则

- 研究基础和成就章节 → 用"申报人"（第三人称客观叙述）
- 自我评价章节 → 用"本人"（第一人称自我陈述）
- 研究计划章节 → 省略主语或被动式（"开展...研究""研制..."）
- 个人信息/成就表单 → 无主语（列表式）

### "首创体"动词链

构建/首创/突破/研制/主导 → 达到/填补/实现 → 获评/入选/荣获

### 排名是关键证据

每个项目/奖项/专利必须标注个人排名（如"主持""参与，4/12""子课题负责人，1/12""排名7/12"）。

# F 类：绩效评价/中期自查报告

## 语体

**对照完成体**。核心逻辑：申报书写了"将做什么"→ 绩效评价写"已完成什么"。所有叙事以"承诺 vs 兑现"为对照轴。

## 语言特征

- **完成时态**："已完成""已取得""已实现""达到了"——不能出现"将""拟""计划"
- **对比思维**：每一个关键指标都要做"承诺值 vs 实际值"的对照
- **值超过承诺→突出展示**；值低于承诺→写"预计X年X月完成"或给出原因
- **证据链密度为所有文种之冠**：表格 + 现场照片 + 第三方检测报告 + 船级社认证 + 审计报告 + 论文首页 + 专利受理通知书
- **问题归因于外部因素**，点到为止，不展开检讨

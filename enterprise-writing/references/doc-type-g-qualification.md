# G 类：企业资质认定申请

小巨人申请书/复核申请书和单项冠军情况介绍归入此类。底层论证逻辑一致：**市场占有率分析 + 企业综合能力论证**。差异仅在输出形式。

## 语体

**市场推理体**（单冠自由文档）/ **证据列表体**（小巨人表单）。核心是宏观→中观→微观的逻辑推算链，用公开行业数据推导企业的市场地位。

## 语言特征

### 子场景识别

用户描述含"小巨人""复核""认定" → 政府表单场景（叙事内容需适配 PDF 表单栏目）
用户描述含"单项冠军""冠军企业" → 自由文档场景（按章节撰写）

识别后向用户确认格式要求（字数限制、是否需要匿名等均以用户提供的政府通知为准）。

### 对白/表单场景的写作原则

政府表单的叙事栏目（市场占有率说明、补短板填空白、企业总体情况等）需在有限字数内完成完整论证链，每个栏目自成闭环。

### 自由文档场景的写作原则

单项冠军类需构建完整的宏观→中观→微观逻辑链，用公开行业数据推导市场地位。关键技术性能对比是核心论证工具之一。

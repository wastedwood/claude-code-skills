# 表单依赖关系与填写顺序

## 依赖图

```
知识产权（IP） ← 先有真实专利
    ↓
人力资源（HR） ← 独立，无依赖
    ↓
研发活动（RD） ← 可选关联 IP
    ↓
费用明细（Fee） ← 必须关联 RD + 年份
    ↓
产品情况（PS） ← 可选关联 IP
    ↓
企业创新能力
  ├── 知识产权作用 ← 自动读取 IP
  ├── 成果转化 ← 关联 IP/RD/PS
  ├── 组织管理 ← 独立
  └── 人员情况 ← 从 HR 表自动带出
    ↓
标准制定 ← 独立，无依赖
    ↓
主要情况表 ← 自动汇总前面所有表
```

## 推荐填写顺序

| 步骤 | 表单 | 原因 |
|------|------|------|
| **1** | 知识产权汇总表 | 其他表用到 IP 关联 |
| **2** | 人力资源情况表 | 研发/产品表不依赖它，但主要情况表汇总 |
| **3** | 研发活动情况表 | 费用表必须关联 RD 项目 |
| **4** | 费用结构明细表 | 按年份逐条填写 |
| **5** | 高新技术产品情况表 | 可选关联 IP |
| **6** | 企业创新能力 | 需关联 IP/RD/PS |
| **7** | 标准制定情况表 | 独立，可随时填 |
| **8** | 主要情况表 | 最后核对自动汇总数据 |
| **9** | 上传附件 | 最后统一上传 |

## 数据流说明

- **IP 数量**(I类/II类)：从知识产权表自动同步到主要情况表
- **职工总数/科技人员数**：从人力资源表自动同步到主要情况表
- **研发费用总额**：从 RD 活动表自动计算到主要情况表（只读）
- **高新收入**：从 PS 表自动计算到主要情况表（只读）
- **成果转化可选关联**：IP/RD/PS 的编号会出现在下拉选项中
